# Hey, I'm Jeon 👋

**Software engineer based in Mandaluyong, Philippines · 4 years of experience · Backend and full-stack development**

I build the systems behind useful products: APIs, data models, integrations, and the interfaces that make them accessible. My work has taken me from digital publishing and fleet operations to fintech. I enjoy seeing a feature through from the first conversation to production support.
